WHAT IS IT?
===========
Better Auth - A secure, modern authentication system for Next.js apps
- Email + Password authentication
- Session-based (7 day cookies)
- Password hashing with bcrypt
- Built-in CSRF protection


HOW TO USE IT (USER SIDE)
==========================

1. SIGN UP
   URL: http://localhost:3000/sign-up
   Steps:
   - Enter name
   - Enter email
   - Enter password (8+ characters)
   - Click "Create account"
   - Auto-redirected when done

   Example:
   Name: John Doe
   Email: john@example.com
   Password: SecurePass123

2. SIGN IN
   URL: http://localhost:3000/sign-in
   Steps:
   - Enter email
   - Enter password
   - Click "Sign in"
   - Auto-redirected when done

   Example:
   Email: john@example.com
   Password: SecurePass123

3. SIGN OUT
   Currently no UI button
   Coming soon: Header with user menu + Sign Out


HOW IT WORKS (DEVELOPER SIDE)
=============================

CLIENT-SIDE (React Components)
-------------------------------

Check if user logged in:
  import { authClient } from '@/lib/auth-client'
  const { data } = await authClient.getSession()
  if (data?.user) { /* logged in */ }

Sign in:
  const { error } = await authClient.signIn.email({
    email: 'user@example.com',
    password: 'password123'
  })

Sign up:
  const { error } = await authClient.signUp.email({
    email: 'user@example.com',
    password: 'password123',
    name: 'John Doe'
  })

Sign out:
  await authClient.signOut()


SERVER-SIDE (Server Actions / API Routes)
------------------------------------------

Get current user ID:
  import { getUserId } from '@/lib/auth-utils'
  const userId = await getUserId() // throws if not logged in

Get full session:
  import { getSession } from '@/lib/auth-utils'
  const session = await getSession()
  // returns: { user: { id, email, name, ... } }

Protect a page:
  import { getSession } from '@/lib/auth-utils'
  import { redirect } from 'next/navigation'
  
  export default async function ProtectedPage() {
    const session = await getSession()
    if (!session?.user) redirect('/sign-in')
    // page content here
  }


DATABASE
========

Two tables automatically created:
  1. "user" - stores email, password hash, name
  2. session - stores active sessions

Password is NEVER stored in plaintext - only the hash
This means even if database is hacked, passwords are safe


SECURITY
========

✓ Passwords are hashed (bcrypt)
✓ Cookies are HttpOnly (can't be stolen by JavaScript)
✓ Sessions expire after 7 days
✓ CSRF protection enabled
✓ Input validation on all fields

⚠️ Not Yet Implemented:
  - Rate limiting (brute force protection)
  - Email verification
  - Password reset
  - Two-factor auth

API ENDPOINTS
=============

All Better Auth endpoints are at: /api/auth/[...all]

Common operations:
  POST /api/auth/sign-up       - Sign up with email/password
  POST /api/auth/sign-in       - Sign in with email/password
  POST /api/auth/sign-out      - Sign out (clear session)
  GET  /api/auth/get-session   - Get current session
