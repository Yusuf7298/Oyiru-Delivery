SYSTEM ARCHITECTURE
================================================================================

Order Creation Flow:
  1. User adds items to cart
  2. User proceeds to checkout
  3. User fills delivery address, city, phone
  4. User clicks "Place Order"
  5. createProductOrder action called with items + delivery info
  6. Transaction begins (BEGIN)
  7. Order inserted into product_orders
  8. For each item:
     - Item inserted into product_order_items
     - Product inventory decremented
  9. Transaction committed (COMMIT)
  10. User redirected to /order-confirmation/[id]
  11. Confirmation page displays order details

Order Retrieval:
  - Query: SELECT * FROM product_orders WHERE customerId = $1
  - Result: Order with all totals and delivery information
  - Items: SELECT * FROM product_order_items WHERE orderId = $1
